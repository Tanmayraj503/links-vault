# Saved Links Vault

A calm place for the links you want to come back to — the rabbit holes, and tiny sparks that make your days better.

## Features

- 📌 Save and organize links into collections
- 🔍 Search across all your saved links
- 🖼️ Custom images for each link (upload or URL)
- 🌙 Dark mode support
- 🗂️ Grid and list view
- 🔄 Drag-and-drop reordering
- 💾 Persistent local storage (no account required)

## Tech Stack

- **React 19** with TypeScript
- **Vite** for bundling
- **Tailwind CSS v4** for styling
- **Wouter** for routing
- **IndexedDB** for photo storage
- **LocalStorage** for link data

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Usage

- Click **add a link** to save a new bookmark
- Drag cards to reorder them
- Use the search bar or category pills to filter
- Toggle between grid and list view
- Switch between light and dark mode with the moon/sun button
